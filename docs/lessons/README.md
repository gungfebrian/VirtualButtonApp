# VirtualButton classroom course

This course teaches physical computing by following one command from an iPhone
to an ESP32 and back again. Complete the units in order; each one builds on the
same working circuit and application.

## Course map

| Unit | Topic | Practical outcome |
| ---: | --- | --- |
| 1 | [GPIO output and the LED](01-gpio-output.md) | Wire and control an LED safely |
| 2 | [BLE services and characteristics](02-ble-service.md) | Read the project's BLE contract |
| 3 | [The iPhone as a BLE central](03-ios-central.md) | Trace discovery, connection, and writes |

## Before class

- Read the safety notes in the [project guide](../../README.md).
- Disconnect USB power whenever changing the breadboard wiring.
- Use a physical iPhone for BLE exercises; the simulator cannot test the radio.
- Keep Serial Monitor set to 115200 baud for firmware observations.

Every lesson includes a learning goal, an activity, questions to discuss, and a
small success check. Students should record observations before changing code;
the difference between prediction and result is where most of the learning is.
